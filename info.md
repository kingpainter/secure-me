# Secure Me — Professional Home Alarm Manager

A comprehensive alarm system integration for Home Assistant with multi-zone support, modular architecture, and an advanced configuration panel.

## Features

- **Multiple Arming Modes** — Away, Home, Night, Vacation
- **Zone Management** — Entry, instant, interior, perimeter zones with sensor groups
- **6 Smart Modules** — Camera, Lock, Lights, Climate, Siren, TTS
- **Health Monitoring** — System health score, per-module health, battery tracking
- **Testing Framework** — Quick, standard, and full system tests with result history
- **Configuration Panel** — Modern sidebar UI with real-time status
- **Notifications** — Configurable alerts with test support
- **Automations** — Custom automation triggers with service execution
- **Battery Tracking** — Auto-discovery of all battery sensors with low/critical alerts
- **Diagnostics** — Full diagnostic download for troubleshooting

## Requirements

- Home Assistant 2025.1.1 or newer

## Installation

1. Install via HACS (recommended) or manually copy to `custom_components/secure_me/`
2. Restart Home Assistant
3. Go to Settings → Devices & Services → Add Integration → **Secure Me**
4. Enter your alarm code and configure delays
5. Access the panel from the sidebar: **Secure Me**
