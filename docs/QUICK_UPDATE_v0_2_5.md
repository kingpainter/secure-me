# Secure Me Panel v0.2.5 - Quick Update

## 📦 Installation (3 steps)

### 1. Backup
```bash
cp /config/custom_components/secure_me/frontend/secure-me-panel.js \
   /config/custom_components/secure_me/frontend/secure-me-panel.js.backup
```

### 2. Upload
Upload `secure-me-panel.js` to:
```
/config/custom_components/secure_me/frontend/secure-me-panel.js
```

### 3. Hard Refresh
- **Chrome/Edge:** Ctrl + Shift + R
- **Firefox:** Ctrl + F5
- **Mobile:** Close app → reopen
