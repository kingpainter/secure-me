# Secure Me - Brands Package Quick Start

## 📦 What You Have

A complete Home Assistant brands package with 8 optimized PNG files ready for submission.

## 🚀 Quick Submission (5 Steps)

### 1️⃣ Fork Repository
```
Visit: https://github.com/home-assistant/brands
Click: "Fork" button (top right)
```

### 2️⃣ Clone Your Fork
```bash
git clone https://github.com/YOUR_USERNAME/brands.git
cd brands
```

### 3️⃣ Add Files
```bash
# Create directory
mkdir -p custom_integrations/secure_me

# Copy all 8 PNG files from this package to:
# brands/custom_integrations/secure_me/
```

### 4️⃣ Commit & Push
```bash
git add custom_integrations/secure_me/
git commit -m "Add Secure Me custom integration branding"
git push origin master
```

### 5️⃣ Create Pull Request
```
1. Go to your fork on GitHub
2. Click "Pull Request"
3. Use template from SUBMISSION_CHECKLIST.md
4. Submit!
```
